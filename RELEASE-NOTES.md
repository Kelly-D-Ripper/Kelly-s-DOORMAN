# Kelly's DOORMAN 1.0

"Incorrect version" is not useful advice. DOORMAN tells you what is missing, wrong, or extra. Apparently that needed a mod.

- A native-style mod checklist before joining and after compatibility failures.
- Show incompatible servers, including dedicated servers the browser normally hides.
- Saved favourites, favourites first, and an Only favourites filter.
- Readable ticks, stars and colours that fit the game.
- Copy report and F8 to reopen the last diagnosis.

**Most players want the FULL download.** Close the game, extract it into your Nuclear Option folder, replace the old JOINCHECK DLLs and restart. Keep your config. Both plugins report 1.0.0 internally.

CLIENT is enough for joining. SERVER is for dedicated hosts. You can keep both installed when joining and occasionally hosting. SOURCE contains the buildable project; SHA256SUMS lists download hashes.

Exact mod lists from hashed Blueprinter versions need the host companion. Other browser filters still apply. Refresh updates known dedicated entries; reopen the browser for newly advertised servers.

Showing an incompatible server does not make it compatible. You still have to fix your mods. Tragic.

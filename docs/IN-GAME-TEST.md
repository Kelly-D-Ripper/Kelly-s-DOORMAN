# DOORMAN 1.0 game check

Status: Aaron confirmed the full 0.3.4 package works perfectly on 5 October 2026 and requested stable 1.0 publication. Both components now report 1.0.0, with version-label changes only. Aaron's earlier screenshot shows the rendered tick, favourite stars and both dedicated and hosted results. The unchanged discovery source previously passed three read-only Steam refreshes with 119 responding dedicated servers each, then passed again after disposal/reopening. The cases below remain a regression checklist, not a claim of individually recorded execution. No managed-server deployment or restart has been performed.

1. Replace the single client DLL and restart. Verify the log loads DOORMAN 1.0.0 and logs "Browser controls attached above the native list" when opening the browser. The filter bar and label backgrounds should blend into the existing browser backdrop, with neutral charcoal checkbox squares and the native green tick. Click both the square and label to confirm the invisible label hit area still works. At the original 3440x1440 resolution, verify the two checkboxes sit above the server rows and the list remains scrollable. The small collapsed square at the bottom-left must be gone. Repeat at 1920x1080 and 1280x720; text, checkbox hit regions, stars and native columns should fit without covering other controls.
2. Click both the checkbox square and its label. A green drawn tick must appear/disappear immediately and the toolbar must show ON/OFF text. With Show incompatible servers off, take note of normal results. Turn it on: a refresh should reveal other versions/mod sets. Test Dedicated, Hosted, then All, including rapid repeated clicks while searching; the latest selection must be applied after the current search completes. Use Global/clear search/full/empty/password/mission filters for the broadest list. Test each native filter afterwards; version override must preserve those filters. Blocked/unadvertised/unresponsive servers remain subject to the game's normal discovery rules.
3. Select an incompatible result. Confirm the row marker and DOORMAN missing/wrong-version diagnostics agree. Normal Join must still reject incompatible versions; revealing them must not bypass authentication. Turn the checkbox off to restore ordinary version filtering.
4. Click a server's outline star. It should fill yellow, move that server into the favourite group, update the count, and keep the server details closed. Click the row name to confirm the stock details popup still opens. Click the filled star to remove it.
5. Before saving any favourites, confirm Only favourites (0) is unchecked and unavailable, and ordinary results appear even if 0.3.0 previously saved FavouritesOnly=true. Save two favourites; the checkbox must become available. Exercise each stock sort header and name search. Favourites should stay first, with the selected native ordering within each group. Only favourites must hide non-favourites without an extra Steam refresh. No matching online favourites should produce an empty list with a visible count/filter that can be unchecked. Remove the last favourite while filtering: the checkbox must switch off and ordinary results return without another Steam query.
6. Refresh repeatedly and switch filters. Dedicated results must remain present. Known dedicated entries update in place; close/reopen the browser to discover newly advertised servers. Close while searching, then reopen; there must be no callbacks to destroyed UI, stuck refresh state or empty list caused by leaked/cancelled requests. Reused/pooled rows must show the correct current server's drawn star. Metadata updates must not duplicate stars or incompatible prefixes. Changing the current server name/mission should preserve its favourite. No missing-glyph warnings for Check/Star should appear in Player.log.
7. Restart the game. Confirm favourite identities and both checkbox settings persist. A dedicated server with a changed Steam server ID at the same endpoint should stay saved. A player who recreates their lobby should stay saved under the same Steam owner. Different ports/hosts must stay independent.
8. Confirm the existing opaque DOORMAN checklist, Details, Copy report, matching-mod toggle, Close/Escape/F8 and unrelated stock errors still work. Return to the main menu and reopen the browser: there should be one toolbar/star per row, without shrinking the scroll view again. Resize the window and exercise scrollbar appearance/disappearance with few/many rows: the toolbar must remain above the list and star spacing must survive layout rebuilds.
9. Roll back to Client 0.2.1 and restart to confirm stock discovery is restored and the prior checklist remains usable. Extra Browser config entries may remain; no database/config migration or server action is needed.


10. Test the server companion on a disposable player-hosted lobby and dedicated server. With hashed Blueprinter versions, confirm missing/wrong/extra mods are available before joining. Ordinary clients must still join without DOORMAN. Keep both components installed on the player-host and test joining another server too. Older JOINCHECK clients/companions should still understand protocol 1.

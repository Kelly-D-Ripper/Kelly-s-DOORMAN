# Mods menu local test

Status: compiled and static/pure-logic checks passed. Actual Unity rendering, loader hooks and multiplayer acceptance are pending. This candidate has not been installed or published by Codex.

Close the game before extracting FULL or CLIENT. Overwrite `BepInEx/plugins/KellysJOINCHECK.dll`, `BepInEx/patchers/KellysDOORMANStartup.dll` and `BepInEx/DOORMAN/KellysDOORMANRestart.exe`. Keep exactly one JOINCHECK client DLL and one startup helper. Preserve the existing config and favourites. Keep the previous working client DLL/helper outside BepInEx for rollback.

For the missing-controls report, preserve the latest BepInEx LogOutput.log and Player.log. Confirm `Plugin runtime host protected before plugin startup` appears before the first plugin-loading marker, followed by `DOORMAN runtime host` with HideAndDontSave and `DOORMAN first runtime update`. Opening either menu must produce `DOORMAN scene event` with its name/path, then the relevant attachment marker. A `runtime disabled` or `runtime destroyed` marker before application quit is a failure and supplies the previously missing lifetime evidence. Do not clear the saved profile or server ticket to try to repair absent controls; their disabled lists already exclude DOORMAN.

1. Start normally. Confirm the player name, all regular menu labels, roadmap text, cursor and menu buttons work. Look for `Client plugin preferences ready; normal Unity startup preserved.`, the DOORMAN 1.3.4 load marker and a native **MODS** button below Workshop. The log must include `Native Mods menu attached after completed startup.` only after loading finishes. Open Multiplayer and confirm the attachment log, Show incompatible servers, Only favourites, star buttons and Check mods on a selected server. Repeat with Blueprinter excluded for a vanilla server, then reopen both menus to check for duplicates. Player.log must contain no early `DontDestroyOnLoad` or `set_hideFlags` MissingMethodException. If recovery fails, preserve Player.log, close the game and move the helper outside the patchers folder before another launch. If the reload adapter rejects the loader, record the displayed reason and the Blueprinter DLL hash.
2. Open Mods at 3440x1440, 1920x1080 and 1280x720. Names, states, pictures, descriptions, links and action buttons must fit. Scroll both columns. Click tick boxes repeatedly; the tick and pending state must update immediately. Back/Escape must return to the menu with normal cursor behavior.
3. Test an author-supplied embedded preview in a bare DLL and a flat DLL/JSON/image installation. Repeat after vanilla setup/restart with Blueprinter and those wrapper plugins disabled: installed content cards and plugin cards must retain their available previews without running disabled code. Close/reopen Mods and switch cards. Confirm manual JSON overrides managed/embedded metadata, while NOMNOM enriches only unmatched cards. Test the exact project snippet in MOD-PREVIEWS.md, one-plugin ID/name inference and explicit multi-plugin IDs. Missing, malformed or oversized previews must leave the mod usable. Remove the old bundled DOORMAN-Previews/aryx folder once; no sample cards/images are shipped in this candidate.
4. Disable one content pack and Reload. Check the encyclopedia and a disposable local mission for absent aircraft/weapons/ships, then leave to the menu. Enable it and reload again. Repeat A -> B -> A several times. There must be no duplicate definitions, hardpoint weapons, hangar entries, loading images or missions.
5. Compare the resulting compatibility string and aircraft/weapon lookup indices with a separate fresh game launch using the same active pack set. Join a matching test host and exercise spawning, loadouts, missiles and damage. Matching names alone do not prove networking correctness.
6. Confirm the checkbox reads **Auto match mods when joining a server**. Turn it on and join a test host with a different subset of locally loaded content. A supported reload applies the exact set and then uses the original join path, including password prompts. An unavailable reload must show **Proceed** and its restart explanation instead of the generic version error. Turn Auto match off and verify **Setup mods** still works. Try another server, an ordinary failed join and rapid repeated Join clicks.
7. Wrong pack version, missing pack, opaque server list, different game version or unsupported loader must not produce guessed removals or skip a game check. A failed final signature comparison must restore the prior active selection.
8. Queue a nonessential code plugin change and Reload. The screen must say a restart is required. Restart and confirm the plugin really stays disabled, including when BepInEx has a discovery cache. Re-enable and restart. Required plugins and dependency conflicts must be protected. Headless/server-only behavior must remain unchanged.
9. Try Reload while connected or while a scene is loading. It must refuse without starting/stopping a host. Verify that opening the native encyclopedia or sorting its lists does not unnecessarily block later reloads.
10. Check old browser filters, dedicated discovery, favourites, checklist, Details, Copy report, F8 and closing/reopening menus. There must be no duplicate buttons or per-frame mod discovery.

11. Open each Aryx card. Its real installed content version must be compared with the latest stable GitHub tag. Current packs say Up to date; older packs offer Update. Both the content and wrapper card use the same content version. Changing/reopening cards must reuse the six-hour cache. Check offline and rate-limited responses; the menu must stay responsive.
12. On a disposable client game copy with an older pack, click Update. Check progress, downloaded checksum/identity, queued state, and unchanged loaded content/current DLL before exiting. With no ticks changed, press Reload mods. Confirm the restart prompt, then Cancel: the game, queue and profile must remain unchanged. Repeat and press Restart game. Also test the card's Restart to finish update action. Verify normal exit and Steam relaunch, the new DLL at the old path, its real installed content version matching the release, and a previous-DLL backup outside plugins. There must be one installed copy and preserved configs. Repeat with another pack and with BepInEx's discovery cache enabled.
13. Test an interrupted download, damaged queued payload, manually changed installed DLL, ambiguous release assets and multi-DLL ZIP. They must preserve installed files and provide a useful message/manual release link. Damaged queued or changed installed files must block an automatic restart before game exit. Check an interrupted post-replacement receipt can reconcile on the next start. Headless startup must not process any client update queue. The restart button must refuse while connected/loading.
14. Compare a busy mission's FPS, CPU and GC with the previous candidate after closing Mods. No updater requests should occur. Profile the page check and explicit download separately; the lack of idle polling is not a measured zero-cost guarantee.

15. Select a mismatched server. **Setup mods** and **Join server** must fit the native checklist at all listed resolutions, including long server names/restart messages. Join stays disabled while the actual live signature differs. Test Setup -> hot reload -> Join, then return to Main Menu and check that the usual saved content returns when hot restore is supported.
16. Select a vanilla dedicated server such as GROUND ZERO with Blueprinter and multiple Aryx packs active. Setup must explain restart, without yet changing files/preferences. Click Proceed. There must be no Invalid saved server error from the game's empty dedicated UDP properties. Confirm one normal game exit/relaunch, Blueprinter and its content wrappers absent from the load markers, DOORMAN still enabled, and the wire version truly vanilla. Verify the exact native server page returns with Join available after all startup loading. Join, leave, quit and launch ordinarily; the saved normal mod set must return.
17. Repeat for a modded hosted server using an installed pack which was disabled at initial load, then for a passworded dedicated host. Required wrappers and hard dependencies must load; unrelated saved plugin choices stay intact. Watch the initial Main Menu -> loader screen -> final Main Menu sequence. The automatic browser transition must happen after final completion and stable input, never during the first menu flash. The password is requested again when joining and is absent from the ticket.
18. While a restart is armed, close the checklist with Close, Escape, F8 or the native details X. It must cancel. Also close it while file verification/helper startup is pending; the game must remain running and a later manual exit must not trigger an unwanted relaunch. Verify a missing helper, unavailable Steam, changed server wire version, offline/disappeared server and consumed/expired ticket each leave a usable menu and useful message.
19. Temporarily move one custom preview manifest outside plugins on the disposable copy. Its matched mod should obtain the NOMNOM author/description/repository; restoring the custom manifest must win. Check an unmatched mod, no-image card, offline local NOMM cache, corrupt registry and repeated card openings. At most one registry fetch occurs per cache refresh. Reopening Mods during a pending fetch must still enrich the current list. No additional registry/image requests occur during a mission.
20. Before restarting, preserve hashes of `doorman-mods.json`, its `.bak`, JOINCHECK config and favourites. After server setup they must retain the normal profile. Inspect the separate return ticket and verify its endpoint, selection and installed-file hashes. Change a disabled pack's DLL before a manual return launch; it must not be trusted as the old version when choosing the next server.
